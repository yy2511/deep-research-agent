# 0001：平台后端用 Python + FastAPI

- 状态：已接受
- 日期：2026-11-05

## 背景

项目要从单人工作台扩展为多用户研究后台。研究引擎、现有接口和测试都是 Python；用户想先通过搭后端学习后端思维，目标岗位语言尚未最终确定。

## 决定

平台接口、业务逻辑和 Worker 都用 Python，沿用 FastAPI。数据库访问用 SQLAlchemy，表结构迁移用 Alembic。

## 考虑过的其他选择

- Spring Boot 写平台接口、Python 只做研究 Worker：更贴近 Java 岗位，但要同时学新语言、维护两套技术栈和跨语言协议，工作量明显更大。

## 代价与影响

- 平台和引擎同一语言，迁移成本低，可直接复用现有测试。
- 若以后转 Java 方向，可按任务表和事件协议另写平台层，研究 Worker 保留。
