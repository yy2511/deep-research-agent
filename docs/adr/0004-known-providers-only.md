# 0004：用户自带 key 只能从已知服务商中选择

- 状态：已被 [0007](0007-public-trial-github-login.md) 取代（2026-11-08）
- 日期：2026-11-05

## 背景

现在的模型配置允许填任意服务地址（Base URL），单人使用时没有问题。开放给多用户后，用户填的地址由服务器去请求；如果填 `http://127.0.0.1:8765` 或云厂商内部地址，就能借服务器访问内网（SSRF）。

## 决定

多用户模式下，用户填写自己的 key 时只能从平台维护的服务商列表中选择，服务地址由平台决定，用户不能自填。管理员配置的平台连接不受此限制。

## 考虑过的其他选择

- 允许任意地址，但拦截内网 IP：要处理 DNS 重绑定、重定向、IPv6 等绕过方式，内测阶段不值得。

## 代价与影响

- 新增的限制：用户无法接入列表以外的中转服务商。需要时由管理员评估后加入列表。
- 现有单人工作台的设置页行为不变；限制只作用于多用户模式下的用户自带 key。
