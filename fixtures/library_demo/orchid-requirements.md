# Orchid 服务需求（模拟资料）

这是一份为演示私域文档研究人工编写的虚构需求，不代表真实客户、企业或已经实现的产品能力。
版本：2026-09-19 / ORC-REQ-07。

## 数据与容量

Orchid 的单文件上传目标上限为 17 MiB。这个数字仅是模拟服务的需求，不是本资料库上传工具的限制。
用户原始资料禁止发送给外部 embedding 服务，向量计算必须在本机完成。
只有经过授权的研究片段可以发送给租户选择的研究模型。
本地研究模式禁止搜索公网，不能为了补齐答案自行切到网页搜索。

## 超时与取消

Orchid 的研究交互软截止时间为 90 秒。到时应停止新增外部请求，保留已取得的证据并说明缺口。
用户取消后已经写入的证据不删除。任务抛出异常也不表示之前保存的材料无效。
不能把 Python 的等待超时等同于所有后台工作已经退出；具体行为需要对照所用并发 API。

## 可追溯性

答案要区分直接记载的事实、跨资料综合的分析和无法回答的问题。
资料库更新后，运行应继续引用创建研究时固定的文档版本。
Orchid 的日志保留规则见 ORC-OPS-12；备份规则见英文数据管理附录的第二页。

## 未提供的信息

此需求没有给出 GPU 采购预算、供应商报价或并发用户数。不能把缺失的数字推断成既定约束。
