# 美股存储板块近期为何大跌？——截至2026年7月22日的成因与展望

## 执行摘要

2026年7月，美股存储板块经历了自AI繁荣启动以来最剧烈的回撤：标杆ETF——Roundhill Memory ETF (DRAM) 自6月22日高点至7月17日暴跌近40%，成分股集体进入熊市[17][6]。本轮大跌由供给端产能扩张引发过剩担忧、需求端AI投资结构性转移与终端库存高企抑制价格传导、以及市场在高估值下集中获利了结三大力量共同驱动。尽管头部公司Q2业绩创纪录，但“买预期、卖事实”的模式、HBM合同锁价导致盈利弹性不足、中国竞争对手IPO等个股利空形成连锁反应，叠加韩国市场流动性危机与程序交易的放大效应，最终酿成板块性踩踏[36][57][71][79]。截至7月22日，多个核心标的较近期高点回撤超过20%-30%，部分AI服务器股价腰斩。当前市场正重新定价存储周期，短期波动可能持续，但HBM与AI长期需求结构性基础尚未动摇，本次调整更可能是一次预期修正，而非多年上行周期的终结[39]。

## 关键发现

- 存储板块标杆ETF——Roundhill Memory ETF (DRAM)自2026年6月22日见顶后至7月17日大跌近40%，跌幅远超同期iShares半导体ETF (SOXX) 的24%和VanEck半导体ETF (SMH) 的20%，凸显该板块是AI交易链条中最脆弱的一环[17][19]。
- 供给端压力是最大担忧：三星、SK海力士、美光同步进行大规模产能扩张，2026年行业资本支出预计超过650亿美元，市场担忧重现2018-2019年价格暴跌50%以上的悲剧[23][24]。
- 需求端出现结构性裂痕：超大规模云服务商将AI预算转向电力基础设施、液冷与定制芯片，存储芯片占增量AI投资的份额缩小；同时终端OEM库存高企，记录级价格导致采购意愿冰封，价格传导链已断裂[26][30][32]。
- 个股层面，尽管美光毛利率升至84.6%历史新高、三星营业利润暴增1800%至89.4万亿韩元，但财报窗口前后获利了结潮爆发；SK海力士HBM长期协议锁价使盈利弹性受损，SanDisk因客户集中度和CXMT 86亿美元IPO牵连暴跌，多家公司内幕交易信号极度负面[57][62][71][79][91]。
- **韩国市场结构性脆弱性放大跌幅**：三星与SK海力士合计占KOSPI市值近一半，国民养老金减持、SK海力士ADR新增供给、程序交易与熔断机制共同将个股抛售演变为系统性踩踏，SK海力士单日暴跌超15%，三星跌超10%[12][69][67][142]。

## 板块整体表现：熊市确认与历史性回撤

自2026年6月25日起，存储板块从长达一年的狂欢骤然转向惨烈抛售。据Yahoo Finance统计，Micron、Samsung、SK Hynix及Roundhill Memory ETF (DRAM) 均下跌超过20%，正式跌入熊市区间[6]。其中，DRAM ETF于4月成立后至6月22日一度飙涨191%至$80.72，随后无抵抗坠落，7月17日盘中触及$48.64，区间跌幅达到39.7%[17][20]。同期，传统半导体ETF也未能幸免：SOXX回撤24%，SMH回撤20%，3倍做多SOXL更暴跌61%[19]。

板块内个股跌幅呈现高度同步性，但回撤深度分化。Western Digital、Seagate、Teradyne、ON Semiconductor、GlobalFoundries等25只半导体股自6月25日至7月中旬均下跌至少20%[9]。半导体板块整体市值蒸发约1.5万亿美元，其中Micron损失近3500亿美元，SanDisk、Intel、Applied Materials、Lam Research各自失血超1000亿美元[7][8]。韩国市场更甚：7月16日KOSPI指数暴跌6.37%，触发熔断；SK Hynix单日重挫超15%，Samsung跌逾10%，均创十年未见的烈度[12][35]。

这一轮暴跌的同步性之强、速度之快，显示出系统性风险厌恶和头寸挤压的特征。特别是在6月底至7月中旬的多日交易中，并无统一触发事件，却出现SanDisk一天跌12.6%、Western Digital跌8.8%、Seagate跌5.7%等同向长阴，表明持仓结构极度拥挤，一旦反转便形成负反馈[126][10]。

## 供给端压力：资本支出竞赛与供应过剩的幽灵

存储芯片历史上每一轮高景气周期都会引发产能竞赛，最终导致价格崩跌，2026年正在重演这一规律。据Ainvest报道，三大制造商同步大幅扩产，全行业2026年资本支出预计超过650亿美元[23]。三星承诺将其产能扩张50%，SK海力士的HBM产线也在全力爬坡，若这些产能于2026年底至2027年初全面投产，结构性供应过剩风险将显著上升[25]。美光自身在最近9个月内的资本支出已达196亿美元，固定资产从466亿美元增至564亿美元[120]。如此庞大的投资规模，令市场迅速回忆起2018-2019年周期：当时三大厂同步扩产后，存储芯片均价暴跌超过50%[24]。

供应紧张的缓解迹象已经浮现。TrendForce虽预计2026年全年NAND Flash市场仍有4-5%的供给缺口，但明确指出供给不足将在2027年下半年消退，届时供需将转正增长，平均售价可能从上涨转为下跌[42][43]。该机构更成为首家预测当前NAND Flash上升周期结束的主要研究机构[43]。更为直接的是，中国长鑫存储（CXMT）的崛起正在打破韩美垄断格局：TrendForce估计中国NAND Flash供应商产能将显著提升，占全球比特产出的近19%[47]；CXMT更筹备86亿美元的科创板IPO，这一消息直接引发了SanDisk、西数等股票的恐慌性抛售[53][79]。

此外，技术扩散也在降低供给壁垒。ASML最新光刻工具有望使更多厂商高效生产存储芯片，削弱现有龙头的制程优势[55]。HBM每GB消耗的晶圆产能约为DDR5的三倍，当前供应紧张正由此驱动，但未来产能快速扩张便可能扭转这一结构性瓶颈[37]。因此，市场定价已经包含了对2027年供给过剩的强烈预期，即便当前合约价格仍在环比上涨。

## 需求侧结构性变化：AI投资转向与终端需求崩塌

需求端正在经历双重挤压：一方面，AI投资的结构性转移使得存储芯片的增量份额缩小；另一方面，天价存储芯片已开始反噬消费端需求。

据247wallst报道，超大规模云服务商正将AI预算从存储芯片转向电力基础设施、液冷散热以及定制芯片（ASIC），存储芯片在增量AI投资中的占比持续萎缩[26]。中国AI初创公司Deepseek和Moonshot K3大模型的发布，进一步引发市场对美国科技巨头AI基础设施支出合理性的质疑[68][124]。这些迹象动摇了投资者对存储芯片需求将无限增长的根本信仰。

终端市场的需求破坏更为直观。TrendForce指出，创纪录的合约价格已使PC和智能手机客户触及承受力极限，Q3采购态度转为保守；智能手机品牌被迫提价以对冲高额LPDRAM成本，但可能导致手机销量下滑[30][31]。Gartner预计，存储芯片涨价将直接减少2026年全球PC和智能手机出货量，OEM通过降低规格来消化成本压力[34]。这反映在消费端存储价格上：美国32GB DDR5套件零售价已连续6个月持平在529美元附近，之前近乎垂直的牛市戛然而止[33]。PC和笔记本电脑终端需求持续疲软，是存储需求走弱的主要终端因素[44]。

更致命的是，OEM库存高企显著降低了买家接受新一轮涨价的意愿，议价空间几乎封死[32]。尽管存储原厂自身库存仍相对健康，但下游模组厂商由于消费需求不振，库存水位较高，这阻断了价格向上的传导通道[46]。TrendForce关于“AI驱动的NAND Flash需求将趋于正常化”的警告，以及PC存储行业因AI热潮推高的需求不会持久的判断，犹如一盆冷水浇灭了市场对长期景气的幻想[27][28]。当供给扩产与需求饱和相遇时，周期拐点的预期便自我实现了。

## 个股利空：创纪录业绩与获利了结的致命碰撞

在行业逆风之中，个股利空扮演了落井下石的角色。最核心的触发因素是：“买预期、卖事实”——超预期的财报反而成为获利了结的出口。

**美光 (Micron, MU)** FY2026 Q3毛利率达到84.6%的历史顶峰，营收同比暴增346%至414.56亿美元，但市场却以约7倍的极低远期市盈率定价，表明投资者根本不信这种利润率可以持续[118][119][121]。创纪录的毛利率被视为不可持续的利润高峰，历史规律表明每当存储芯片厂毛利率突破80%，竞争者便会疯狂扩产至价格崩盘[60][119]。同时，高盛下调SK海力士评级引发HBM定价竞争担忧，美光也一道下跌4%[49][50]。台积电资本支出超600亿美元的消息，更让整个半导体估值承压，美光跟跌5.7%[51][52]。长鑫存储86亿美元IPO再次点燃中国竞争恐慌，美光单日大跌8.2%[53]。尽管美光手握220亿美元的take-or-pay合约，仍未能阻挡获利盘涌出[119]。

**三星电子 (Samsung, 005930.KS)** 在7月7日发布了一份史上最强业绩：Q2营业利润89.4万亿韩元，同比增长1800%[129][62]。然而，营收171万亿韩元未能达到市场预期，且DRAM涨价幅度低于交易员此前数月计入的隐含水平，这成为抛售的导火索[62]。由于股价此前已飙升近150%，摩根士丹利报告警示DRAM价格增速放缓与库存改善企稳，引发了“好消息出尽”的暴跌，股价当日重挫近10%[131][133]。此外，三星宣布新建远离现有产业集群的大型晶圆厂，引发对成本效率和执行风险的担忧[65]；劳动力成本上升、国民养老金规则性减持以及Deepseek自研芯片的新闻，共同完成了一轮完美的利空组合[66][67][68]。

**SK hynix (000660.KS / SKHY)** 在7月13日创下近二十年最大单日跌幅15.4%[70][135]。直接触发因素是KIS将其Q2利润预期下调8%，原因在于HBM的长期协议（LTA）锁定了价格，导致公司未能充分受益于现货涨价周期[71]。这暴露了一个残酷现实：HBM业务占比越高，短期盈利弹性反而越差。更糟糕的是，市场期待的HBM4芯片量产于Q2并未实现，业绩预期落空[72]。纳斯达克ADR发行相当于新增供给，加剧了首尔股价的抛压[142]。地缘政治黑天鹅——美国对伊朗空袭及霍尔木兹海峡封锁——则进一步打击了风险偏好[73]。

**SanDisk (SNDK)** 在7月中旬连遭重创：管理层因企业存储需求软化而下调收入指引，并警告NAND均价正加速下跌[76][77][82]。中国CXMT 86亿美元IPO的消息对该公司犹如晴天霹雳，直接触及竞争加剧与供应过剩的痛点，股票应声暴跌[79]。此外，Argus Research给出“持有”评级，指出AI驱动估值已过度；公司自身客户高度集中于少数AI超大规模厂商，令其在需求转向时脆弱无比[80][85]。SanDisk的P/E一度达45倍，巨大的估值压力最终不可持续[86]。

**西部数据 (Western Digital, WDC)** 的二季度财报显示营收同比大降29.6%，毛利率压缩[90]。内部人在过去半年内执行42笔卖出、零买入，机构FIL LTD和FMR LLC分别减持91.8%和26.4%的持股，这些信号对市场信心的打击几乎是毁灭性的[91][92]。在“三星财报狂喜”引发的全盘获利潮中，WDC单日跌8.5%[93]。

**AI服务器及系统厂商**同样未能幸免。Super Micro (SMCI) 因Q3营收102.4亿美元远逊于预期（-17.75%）、经营现金流负66亿美元、台湾芯片走私调查及美国ITC专利调查等多重利空，股价一个月下跌16.8%，年内累跌近半[101][152][154][155][157]。Dell (DELL) 7月15日单日暴跌14%，UBS降级、AI服务器毛利率从21%下滑至18%及巨额内幕卖出（约15.6亿美元）是主要推手[109][110][111][166]。HPE (HPE) 跌8%，分析师下调评级，指出估值已完全反映乐观预期[113][170]。

**企业存储系统** NetApp (NTAP) 和 Pure Storage (PSTG) 分别跌8.6%和11.1%，基本上完全由板块性重定价驱动，自身基本面并无骤变[96][144]。不过NetApp公共云ARR增速放缓与产品毛利率下降仍暗示逆风[146][147]。存储控制器厂商Silicon Motion (SIMO)一个月跌17.83%，估值溢价是核心压力，其远期PE显著高于行业均值[172][171]。

## 综合分析：如何从繁荣到踩踏——因果链与跨市场放大

存储板块的崩盘并非单一维度的灾难，而是供给、需求、市场结构与情绪共振的经典案例：

**因果链分解**：创纪录的高利润率（美光毛利率84.6%、三星营业利润大增1800%）触发了历史宿命——所有存储巨头同步激进扩产（资本支出>650亿美元）→ 市场预期2027年供给过剩 → 尽管Q3合约价格仍在涨，但涨幅已趋缓，且实质性的需求破坏形成（OEM减购、消费级零售价停滞、云厂商预算转向）→ 价格传导链断裂，投资者开始计入周期顶部 → 持仓高度集中的获利盘涌出，又逢韩股结构性脆弱性（NPS减持、ADR供给、程序交易）→ 流动性挤兑导致自我加强的暴跌。

**钢铁人论证（Steelman）——反面观点**：有分析师认为，这一轮只是健康的“预期修正与杠杆削减”，而不是AI存储多年上升周期的终结[39]。HBM市场的结构性需求远未满足，SanDisk手握620亿美元的长期协议最低收入承诺，美光也有数百亿take-or-pay订单，单纯现货价格波动不足以否定长周期逻辑[127][119]。此外，供给端看似庞大，但HBM每GB消耗三倍晶圆产能，转换效率限制了实际产出增长，可能延迟过剩浮现[37]。这一派认为此次暴跌更多是估值重估，而非基本面崩溃。

**权衡判断**：钢铁人观点确有部分支撑，特别是HBM结构性能欠缺长期驱动，但其局限在于低估了传统DRAM/NAND供需的边际逆风以及市场情绪的自我实现力量。证据权重显然倾向于短期逆风占主导：TrendForce作为最权威的存储研究机构，已明确发出NAND Flash上行周期终结的警告[43]；中国新产能入市将在未来12-18个月内实质性改变全球份额版图[47]；下游终端需求破坏是硬数据，而非猜测[34]。更重要的是，存储板块周期反转的历史范式具有极高的胜率——1980年代后的六次大周期中，每次价格跌破现金成本前均出现类似的扩产-过剩循环[24][60]。

**跨市场传染机制**：本次暴跌中，韩国市场扮演了放大器而非单纯反应的角色。三星与SK海力士合计占KOSPI市值近一半，一旦两者同时被抛，指数ETF与程序交易立即触发sidecar和熔断，将个股抛盘指数化、机械化地砸向所有关联仓位[69]。SK海力士ADR上市则引发了跨市场的套利性重定价，分流了韩股买家[74]。此外，美国科技股高估值下的脆弱性共振：TSMC资本支出上调引发美半导体股普跌，美光、SanDisk、WDC均遭波及；AI交易从龙头外溢至存储配件，退潮时亦无差别出清[52][88]。因此，即使基本面相对稳固的公司，也无法逃脱被“绑架上绞架”的命运。

## 局限与口径说明

本报告综合了截至2026年7月22日的公开市场信息、行业机构报告及新闻评论，但存在以下局限：

- **数据时效**：多数股价跌幅数据来自7月中上旬，7月下旬的进一步调整（如SMCI 7月22日再跌7.8%）未被完全纳入。部分证据的日期字段缺失，确切时点难以验证。
- **价格预测口径差异**：不同机构对Q3存储合约价格的预测存在分歧，例如TrendForce给出的DRAM合约价涨幅为13-18%[29]，而其他来源可能有略高或略低的估计，这影响对涨幅趋缓程度的判断。
- **个股覆盖不完全**：虽然已整合了板块内主要公司的利空，但对于Everspin (MRAM)、FormFactor (FORM)等较小市值或利基公司，公开可得的7月股价下跌原因证据有限，仅能推断其跟随板块波动。
- **归因复杂性**：7月中旬的霍尔木兹海峡封锁等外部地缘事件[73]与板块下跌时间重合，其对存储板块的独立影响程度无法精确剥离，风险偏好的整体收缩可能混淆了部分因果。
- **产能预测的未验证性**：各厂资本支出计划多为企业指引或第三方预测（如三星50%产能扩张），实际执行可能受到地缘政治、技术瓶颈或需求变化的影响而调整。

尽管存在上述局限，整体证据链已足够支持主要结论：供给过剩预期、终端需求破坏和市场结构性集中仍是主导存储板块大跌的核心因素。

## 结论与展望

**结论**

1. **下跌性质**：2026年7月存储板块暴跌是一次由供给过剩预期主导、需求疲软证实、高估值和持仓集中度引爆的周期性修正，而非纯粹恐慌错杀。以DRAM ETF近40%的峰值回撤和核心股集体落入熊市为标志，本轮存储上行周期大概率已在6月底见顶。
2. **主要矛盾排序**：供给端大规模扩产（资本支出>650亿美元、CXMT入局）是最底层的担忧；需求端AI投资转结构、终端库存高企与价格反噬构成了中间层；韩国市场结构性脆弱性（GNPS减持、指数联动熔断）与程序交易则在顶部截断了流动性，将调整升级为踩踏。
3. **个体差异**：HBM相关资产虽短期盈利弹性不足（由于LTA锁价），但长期需求确定性最高；纯NAND/HDD厂商将在未来过剩环境中面临最大的边际压力；AI服务器厂商的估值已大幅收缩但盈利可见度仍受制于高比例关联交易和内幕信心缺失。

**展望**

未来6个月，市场将面临两个检验：一是Q3财报季能否止住盈利预测下调的趋势，特别是SK海力士HBM4量产的进展；二是CXMT IPO及中国产能爬坡是否如期而至。若宏观需求未加速恶化，鉴于存储板块估值已跌至历史低位（MU远期PE约7倍，SMCI仅9倍），挤压过后的修复行情可能由任何供给端利空出尽或需求端超预期回暖所触发。但若2027年供给过剩证伪了AI长期需求故事，则存储板块可能迎来类似于2018-2019年的漫长去库存周期，届时选股将比择时更为关键。
