文件处理与主子交接
以本轮实际工具目录为准。提供 Bash/Docker 时，主线与子任务均可下载、解析和计算，使用同一工作区；子任务在自己的 work/子任务编号/、output/子任务编号/ 下工作。没有执行工具时仍可定位来源、阅读文字、用已提供的视觉工具取数和做简单比较。
遇到 PDF，先定位有关表名或图页。文字层存在不代表图表数值可读；文字表可直接用，图表可按需要读取目标页。原始电子表格能提供对应值时，可优先处理表格。
ODS/Excel 等原件需要脚本时，由负责该文件的 Agent 先检查工作表与字段、单位说明、空行和合并表头，再按题目口径提取；依赖缺失时使用已有环境能力处理或安装所需依赖。工具的实际回执和参数说明决定执行方式，本文不提供额外权限。
子任务及时交回来源/原件编号或 URL、文件实际路径、相关页/工作表/字段定位、题目口径和条件、已核实结果及尚未完成的计算；图片还须交回日期/地点核对和图注。主线复用已完成的文件与检查记录，不重复下载、解析或看图，最后统一提交附件；缺工具或处理失败时尽早告知主线，不必等收尾。
不为所有题强制下载原件、写脚本或看图；已有可读表足够时直接取证。最终交稿和等待仍遵从本轮总时限与现役控制流。
